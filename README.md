# Портфолио Александра Колдина

Сайт-резюме на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev       # локально: http://localhost:5173
npm run build     # сборка в папку dist
npm run preview   # посмотреть собранную версию
```

Нужен Node.js 18 или новее.

## Где что менять

- `src/config/site.ts` — контакты, ссылки, тексты правил, стек. Всё в одном месте.
  - `links.resume`: положите PDF в папку `public` и укажите путь, например `'/Koldin_Frontend.pdf'`.
  - `links.github`: ссылка на профиль GitHub.
  - Пока ссылка равна `null`, кнопка на сайте не показывается, чтобы не было нерабочих кнопок.
- `public/portrait.webp` — фото в блоке «Обо мне».
- `src/styles/global.css` — цвета, шрифты, общие отступы (переменные в `:root`).

## Структура

```
src/
  App.tsx              сборка страницы из блоков
  config/site.ts       данные сайта
  hooks/
    useReducedMotion   учитывает системную настройку «уменьшить движение»
    useReveal          появление блока при прокрутке (Intersection Observer)
  components/
    Header             липкая шапка и полоса прогресса прокрутки
    Hero               первый экран на 100dvh
    TypedRole          печатающаяся строка «работаю с …»
    Marquee            бегущая строка технологий
    About              «Обо мне» и три правила
    Stack              основной стек и дополнительные технологии
    Contact            контакты
    Spotlight          свет за курсором
    Footer
```

Стили написаны по БЭМ: у каждого компонента свой CSS-файл рядом.

## Решения, о которых могут спросить

- **Печать строки** живёт в отдельном компоненте `TypedRole`, поэтому таймер перерисовывает только его, а не всю страницу.
- **Свет за курсором и полоса прогресса** двигаются через `style` напрямую и `requestAnimationFrame`, без `setState`: движение мыши и прокрутка не вызывают ререндер.
- **Появление правил** сделано на `IntersectionObserver` и CSS-переходах, без библиотек анимации.
- **Доступность:** семантические теги, `aria-label` у иконок, видимый фокус, отключение анимаций при `prefers-reduced-motion`.
